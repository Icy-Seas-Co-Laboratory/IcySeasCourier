# ADR-005: SHA-256 identifies logical source bytes

Status: Superseded by the configurable digest policy retained in manifest v3

Each source file is hashed with streaming SHA-256. The later ingest worker must independently reproduce the digest after transport decoding before a dataset can be complete.

Manifest v3 transfers record the setup-selected algorithm explicitly and permit SHA-256, 128-bit XXH3,
or BLAKE3. The Registry independently applies the recorded algorithm after
transport decoding; algorithm changes affect new transfers only.
